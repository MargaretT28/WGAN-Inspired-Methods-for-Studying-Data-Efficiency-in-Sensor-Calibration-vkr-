# Применение WGAN-подхода для изучения зависимости точности сенсорной калибровки от объёма данных


В данном репозитории находится код и логи основных экспериментов проекта

- Файл wgan_gp_config.ipynb содержит в себе итоговую реализацию метода.

- В папке logs можно найти логи основных экспериментов работы

- В папке old находятся некоторые промежуточные файлы, сохранённые в процессе работы над проектом


Чтобы повторить эксперименты достаточно скачать ноутбук с финальной версией, проставить свои данные для логирования (или закоментировать нужные строки, если без логирования), при необходимости изменить параметры эксперимента и прогнать ноутбук
